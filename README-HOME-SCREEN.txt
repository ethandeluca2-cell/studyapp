9709 Maths Study Hub — Home Screen / PWA version

IMPORTANT: An iPhone can only add this as a proper app-like home-screen web app when it is hosted on an HTTPS website. Opening index.html directly from Files is not enough to enable install/offline features.

Easiest free route using GitHub Pages:
1. On a computer, sign in to GitHub and create a new public repository, e.g. 9709-maths-hub.
2. Upload all files and folders from this package (index.html, manifest.webmanifest, sw.js, icons/).
3. In the repository, open Settings → Pages.
4. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
5. Wait for GitHub Pages to publish the site. The URL will look like https://YOUR-USERNAME.github.io/9709-maths-hub/
6. On your iPhone, open that URL in Safari.
7. Tap Share → Add to Home Screen. If shown, enable “Open as Web App”, then tap Add.

After it is hosted, the app can cache its shell for offline use. Progress remains saved in that browser/device and does not automatically sync between devices. Past-paper links need internet.

You can also use another HTTPS static host. Keep the files in the same relative folder structure.
